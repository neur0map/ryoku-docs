After install, the machine reboots into SDDM. Pick the **Ryoku (Hyprland)**
session and log in.

## What you see

- **The frame.** A rounded screen border, the desktop's signature chrome.
  Popouts melt into it instead of floating on top.
- **The bar.** QS Bar, the default top bar: the launcher, workspaces, the
  clock, the tray, and status live here. You can switch it for Sumi, a slim
  left rail, from the welcome tour or Ryoku Settings.
- **The wallpaper, with the desktop widgets you enable — a clock, a calendar,
  and a music player — painted on it.**
- **No windows yet.** Hyprland is a tiling compositor, so nothing is open
  until you open it.

`Mod` is `Super` (the Windows or Cmd key on most keyboards).

## The first-run welcome

The first time you log in, a short welcome walkthrough opens over the desktop.
It shows once — on a fresh ISO install, after the shell installer, and one more
time when you update into a release that reworks it — so a machine that has
already seen the current tour is left alone.

  </Step>
  <Step title="Make it yours">
    The knobs most people want first, previewed live as you change them:

    - **Interface scale** — the fix when everything looks oversized on first boot.
    - **Bar** — QS Bar, the full top bar, or Sumi, a minimal left rail.
    - **Desktop widgets** — toggle the Clock, Calendar, and Music player on or off.
    - **Wallpaper** — shuffle a new one and the whole desktop recolors to match.

    Colours, rounding, and the deeper shell knobs wait in Ryoku Settings.
  </Step>
  <Step title="You're set">
    A send-off that points at Ryoku Settings (`Mod + ,`) for everything else.
  </Step>

You can reopen every one of these controls later in **Ryoku Settings**
(`Mod + ,`).

## Four keys worth pressing first

<CardGroup cols={2}>
  <Card title="Open a terminal" icon="terminal">
    `Mod + Return` launches `kitty`, the shipped terminal.
  </Card>
  <Card title="Open the launcher" icon="search">
    `Mod + Space` opens the app launcher. Type to filter, Enter to launch.
  </Card>
  <Card title="Open Ryoku Settings" icon="sliders" href="/docs/settings">
    `Mod + ,` opens the Hub, the live control center for the whole desktop.
    See [Settings](/docs/settings).
  </Card>
  <Card title="See every shortcut" icon="keyboard" href="/docs/keybindings">
    There is no separate legend key. **Ryoku Settings** (`Mod + ,`) lists every
    shortcut live and lets you rebind any of them, and the
    [Keybindings](/docs/keybindings) page is the printed reference.
  </Card>
</CardGroup>

## If nothing draws

If the bar, the launcher, or Ryoku Settings fail to appear, switch to a TTY
(`Ctrl + Alt + F2`), log in, then restart the shell and read its log:

```bash
ryoku reload
tail -n 80 ~/.local/state/ryoku-shell.log
hyprctl binds
```

[Troubleshoot](/docs/troubleshoot) covers the common boot and login issues.
